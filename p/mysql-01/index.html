Table

表（Table）数据库的下一级单位，是数据库中存储数据的核心单元。表的每一行被称为记录（Record），每一列被称为字段（Field）。下面首先介绍常用的字段类型。

1
2
3
4
5
6
7

INT -- 整数
VARCHAR(size)  -- 字符串类型，size为字符串长度
DATE -- 日期类型
TIMESTAMP -- 时间戳类型
BOOLEAN -- 布尔类型
DECIMAL(precision, scale) -- 浮点数类型，precision为精度，scale为小数位数
BLOB -- 二进制 large object

然后介绍表中比较特殊的字段类型。

  • PRIMARY KEY 主键 是用于唯一标识表中每一行数据的字段或字段组合，其值必须唯一且不能为空。
  • FOREIGN KEY 外键 是用于建立和强制表与表之间关联关系的字段，它指向另一张表的主键，确保数据引用的完整性。

CREATE TABLE table_name (
    field_name1 field_type1,  
    -- 字段后面还可以加一些关键词来进行修饰
    -- UNIQUE 唯一
    -- NOT NULL 不能为空
    -- AUTO_INCREMENT 自增
    -- DEFAULT 默认值
    field_name2 field_type2,
    field_name3 field_type3,
    ...
    PRIMARY KEY (field_name1)  -- 设置主键,也可为组合主键
    FOREIGN KEY (field_name2) REFERENCES another_table(field_name?)
)  -- 创建一个表

DROP TABLE table_name;  -- 删除一个表

SHOW TABLES;  -- 查看所有表

DESCRIBE table_name;  -- 查看表结构

Alter table table_name add column field_name field_type;  -- 添加字段

Alter table table_name drop column field_name;  -- 删除字段
