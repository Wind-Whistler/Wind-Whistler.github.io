函数定义

函数是将可复用的代码封装起来的语句组，用于实现特定功能。基本语法如下：

1
2
3
4

def 函数名(参数1, 参数2, ...):
    """函数注释"""
    函数体
    return 返回值
  • 即使无参数，括号必须保留，冒号不可省略，函数体需缩进。
  • return 可在任意位置结束函数并返回值；无 return 或 return 后无值，默认返回 None。
  • Python 支持函数嵌套定义：在函数内部可定义另一个函数，但内部函数仅在外部函数内生效，无法在外部直接调用。若内部函数逻辑简单且仅使用一次，嵌套定义的实际意义不大。

def add(x,y):
    def mul(x,y):
        return x * y
    return x + y

x = 2
y = 3
print(add(x,y))  # 正常执行
print(mul(x,y))  # 会报错

函数调用 函数定义后需通过调用执行，调用时传递的实际参数会自动赋值给形式参数。调用格式为 函数名(实参)，调用后得到返回值。未调用时函数代码不会执行。

参数传递

参数传递本质是赋值过程，解释器根据实参自动推断形参类型。

位置参数

调用时实参与形参顺序、数量必须严格一致，否则会报错。

def cop(x,y,z):

y = 4
z = 5
cop(x,y,z) # 3,4,5
cop(z,y,x)  # 5,4,3
cop(1,2,3,4)  # 报错

默认值参数

定义时为参数指定默认值（如 def func(a, b=5)），调用时可省略该参数，使用默认值。注意：

  • 默认值参数右侧不能再有无默认值的普通位置参数。
  • 默认值仅在函数定义时初始化一次。若默认值是列表、字典等可变对象，多次调用且不传该参数时，会基于前一次调用的结果修改。

def update(s,l = []):
    l.append(s)
    return l

print(update(4,[1,2,3]))  # [1,2,3,4]
print(update(5))  # [5]  会默认创建空列表l
print(update(6))  # [5,6]  默认列表只创建一次，之后不会重复初始化
print(update(7))  # [5,6,7]  同上

关键参数

调用时通过 参数名=值 传递，无需严格对应形参顺序，提高灵活性（如 def func(a, b): pass，可调用 func(b=2, a=1)）。

可变长度参数

  • *parameter：接收多个位置参数，打包为元组（如 def func(*args): pass，调用 func(1,2,3) 时 args=(1,2,3)）。

def f(*tul):  # tul代表很多参数,以元组形式传入
    return tul

def m(*tul):  
    return max(tul)

print(f(1,2,3))  # (1,2,3)
print(m(1,2,3))  # 3
  • **parameter：接收多个关键参数，打包为字典（如 def func(**kwargs): pass，调用 func(a=1, b=2) 时 kwargs={'a':1, 'b':2}）。

    print(p)

def demo2(**p): 
    print(p.values())

def demo3(**p): 
    print(p.keys())

demo1(x = 1,y = 2,z = 3)  # {'x': 1, 'y': 2, 'z': 3}
demo2(x = 1,y = 2,z = 3)  # dict_values([1, 2, 3])
demo3(x = 1,y = 2,z = 3)  # dict_keys(['x', 'y', 'z'])

序列解包

调用时可用 * 解包序列为位置参数（如 lst=[1,2,3]，func(*lst) 等价于 func(1,2,3)）；用 ** 解包字典为关键参数（如 dic={'a':1, 'b':2}，func(**dic) 等价于 func(a=1, b=2)）。注意：* 解包的参数会被优先处理为位置参数，若与关键参数冲突（如 func(a=1, *(2,3))），会因同一参数被重复赋值报错。

def fun(a,b,c):
    print(a,b,c)

fun(a = 1,*(2,3))  # 报错:fun() got multiple values for argument 'a'
fun(b = 1,*(2,3))  # 报错:fun() got multiple values for argument 'b'
fun(c = 1,*(2,3))  # 输出2,3,1

变量作用域

变量起作用的范围称为作用域，分为局部变量和全局变量：

  • 局部变量：函数内部定义的普通变量，仅在函数内有效，函数结束后自动删除。
  • 全局变量：函数外部定义的变量，全局可用。

变量查找规则：函数内优先查找局部变量，未找到则向外查找全局变量。若局部变量与全局变量同名，局部变量会隐藏全局变量。若需在函数内修改全局变量，需用 global 声明（如 global x，之后对 x 的赋值会反映到全局）。注意：函数内只要有赋值操作，该变量即为局部变量（除非用 global 声明），直接引用未赋值的局部变量会报错。

def t():
    global x  # 声明全局变量
    x = 3
    y = 4
    print(x,y)

t()  # 3 4
print(x)  # 3
print(y)  # name 'y' is not defined

lambda表达式

lambda 用于创建匿名函数，语法为 lambda 参数: 表达式，仅能包含一个表达式，结果为返回值。适合定义简单临时函数（如 f = lambda x, y: x+y，调用 f(1,2) 返回 3）。可设置参数默认值（如 g = lambda x, y=2: x+y），也可在表达式中调用其他函数。

g = lambda x, y = 1, z = 2, : x + y + z 
print(f(2,3,3))  # 8
print(g(2))  # 5

def lina(x):
    return 3 * x + 1

l = [1,2,3,4,5]
L = list(map(lambda x: lina(x), l))
print(L)  # [4, 7, 10, 13, 16]
