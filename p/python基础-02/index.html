Numpy简介

Python列表的局限性

  • 形式灵活但效率低：Python原生列表允许每个元素拥有不同的数据类型，这虽然提供了极大的灵活性，但在科学计算中却成为了性能瓶颈。由于列表存储的是对象的引用，且类型不统一，程序在进行计算时必须通过循环逐个遍历元素，并实时检查每个元素的类型，这导致了大量的额外开销，运算效率较低。

NumPy概述

  • 全称：Numerical Python。
  • 核心功能：NumPy是Python科学计算的基础包，它提供了大量高效的库函数和操作，专门用于处理数值运算。它弥补了Python原生列表在处理大规模数据时的性能缺陷，是实现高性能计算的关键工具。

核心数据结构：ndarray

  • 存储方式：NumPy采用n维数组对象（ndarray）的方式进行存储。这种结构在内存中是连续存储的，极大地提高了数据访问和运算的速度。
  • 同质性要求：与列表不同，ndarray里的存储元素必须是同一类型的数据。这种强类型约束使得NumPy能够利用底层C语言的优化，进行矢量化的数学运算，从而显著提升计算性能。

# 其他创建数组的方法
vec = np.arange(0,10,0.1)  # begin end step  等差数列的创建，不返回右端值

# 创建随机数组

vec = np.random.randint(0,10,10)  # 创建10个0-9之间的整数  参数为start end size
mat = np.random.normal(loc = 0, scale = 2, size = (3,3)) # 生成正态分布随机数，loc代表期望 scale代表标准差 size为形状 

# 特殊数组的创建
mat = np.zeros((5,5))  # 创建5*5的全零矩阵 dtype为float
mat = np.ones((5,5))  # 创建5*5的全一矩阵 dtype为float
mat = np.empty((5,5))  # 创建5*5的空矩阵
mat = np.identity(3)  # 创建3*3的单位阵
mat = np.eye(4,3,k=-1)  # eye相较于identity更灵活，不一定是方阵，k代表对角线偏移

# 其他
mat_A = np.random.normal(loc = 0, scale = 2, size = (3,3))
mat_B = mat_A.copy()  # 开辟一块内存把数据复制过去，直接mat_B = mat_A 并不会开辟新内存
mat_C = np.zeros_like(mat_A)  # 创建和mat_A形状一致的全零矩阵
mat_C = mat_C.astype('int')  # 类型转换函数astype

# 一维数组的切片(左闭右开)
vec[0]  # 返回第一个元素
vec[0:2]  # 返回前两个元素

vec[-3:]  # 负索引，返回倒数第三个元素到最后一个元素

# 二维数组的切片
mat[0,0]  # 返回第一行第一列的的元素
mat[0:2,0:2]  # 返回一个子矩阵
mat[::2,:]  # 取偶数行
mat[-1,-1]  # 返回最后一行最后一列的元素

# 数组与标量之间的运算
mat = np.linspace(1,100,100).reshape(10,10)
print(mat + 2)  # 每个元素加2
print(mat * 2)  # 每个元素乘2
print(mat ** 0.5)  # 每个元素开根号

# 数组与数组之间的运算
a = np.array([1,2,3])
b = np.arange(1,4)
print(a + b)  # 数组相加
print(a * b)  # 每个位置相乘
print(np.sin(a))  # 每个位置取sin
print(np.log(b))  # 每个位置取log

# 其他
wts = np.array([0.3,0.3,0.4])
print(np.average(a))
print(np.average(a, weights = wts))  # 加权平均

i = wts.argmax()  # 取出最大值的坐标
print(i)
j = np.where(wts < 0.4)  # 取出小于0.4的坐标
print(j)
