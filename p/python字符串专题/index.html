字符串基本知识

字符串属于不可变有序序列，支持比较大小、计算长度、索引访问、切片、成员测试等操作，但不支持原地修改，既不能增删改字符，切片也只能读取元素，无法改变原字符串内容。

定义字符串可使用单引号、双引号、三单引号或三双引号作为定界符，不同定界符支持互相嵌套。其中单双引号用法一致，三引号适合包裹包含引号的内容或多行文本。

字符串中可通过转义符\表达特殊含义，比如\n表示换行、\t表示水平制表符、\"和\'分别输出单双引号、\\输出反斜杠本身，也支持用八进制、十六进制等形式表示字符。若不想让转义生效，可在字符串前加r定义为原始字符串，所有字符都会保持字面含义，常用来书写文件路径。

注意字符串的所有“修改”类方法都只会返回新的字符串，不会对原对象做任何改动。

1
2
3

print('a\nb')  # a b 分两行输出
print(r'a\nb')  # 输出a\nb
print('\\','\'','\"')  # 输出\ ' "

字符串格式化

格式化是对字符串进行格式表达的方式。换句话说，要规定它输出的表达方式。 Python共支持三种字符串格式化方式，分别是format方法、%运算符、格式化字符串常量（f-string）。

format()方法

语法为<模板字符串>.format(<逗号分隔的参数>)，模板中用一对{}作为占位槽，默认按顺序匹配参数，也可手动指定序号，例如：

1
2

"{}的CPU占用率为{}%".format("C", 10)       # 按顺序匹配
"{1}的CPU占用率为{0}%".format(10, "C")    # 指定序号，输出"C的CPU占用率为10%"

槽内部可通过{<参数序号>:<格式控制标记>}添加格式规则，控制标记顺序固定为：<填充><对齐><宽度><千位分隔符><精度><类型>。

  • 填充、对齐、宽度常搭配使用：<左对齐、>右对齐、^居中对齐，不足宽度时用指定字符填充：
1
2
3
4

"{:*>10}".format("BIT")    # 右对齐，*填充，宽度10，输出"*******BIT"
"{:^10}".format("PYTHON")  # 居中对齐，空格填充，输出"  PYTHON  "
"Hello!{:&^10}".format('World')  # 'Hello!&&World&&&'
"Yes,{:+<20}".format('Sir')  # 'Yes,Sir+++++++++++++++++'
  • 数字相关格式：,为千位分隔符，.精度控制浮点数小数位或字符串最大长度，类型支持进制、科学计数法等转换：
1
2
3
4
5
6
7

"{:,.2f}".format(12345.6789)   # 输出"12,345.68"
"{:b}".format(10)              # 转二进制，输出"1010"
"{:.2%}".format(0.25)          # 百分比，输出"25.00%"

# 复杂一些
"Take that!{:,.3f}".format(3.1415926)   # ','开启千分位，'.3'精确到小数点后3位，'f'指定为浮点类型，输出'Take that!3.142'
"Hold it!{:*^11,.2%}".format(1.234567)  # 输出'Hold it!**123.46%**'

%运算符格式化

用法类似C语言，通过%连接格式字符串和参数，常用格式符：%s字符串、%d十进制整数、%f浮点数、%x十六进制、%%输出百分号本身：

1
2

"姓名：%s，年龄：%d" % ("张三", 20)    # 输出"姓名：张三，年龄：20"
"圆周率：%.2f" % 3.14159             # 保留两位小数的浮点数，输出"圆周率：3.14"

格式化字符串常量（f-string）

Python 3.6+新增的写法，字符串前加f，直接在{}中嵌入变量或表达式，也支持复用format的格式控制规则：

1
2
3
4
5

name = "李四"
age = 22
print(f"姓名：{name}，明年{age+1}岁")    # 输出"姓名：李四，明年23岁"
value = 11/3
print(f"结果：{value:10.4f}")         # 宽度10，保留4位小数，输出"结果：    3.6667"

字符串常用操作

Python字符串操作特性

Python字符串对象内置了大量方法，用于处理切分、连接、替换和排版等操作。除了方法之外，Python还提供了一些内置函数和运算符来辅助字符串处理。

需要特别强调的是，字符串对象具有不可变性。这意味着一旦一个字符串被创建，就无法直接对其进行原地修改，比如增删某个字符。因此，所有涉及“修改”操作的方法（如替换、切割等）都不会改变原始字符串，而是会生成并返回一个新的字符串对象。这种机制保证了原始数据的安全性，但也意味着如果需要保留修改后的结果，必须将返回值重新赋值给一个变量。

查找位置和统计次数

find() 与 rfind()

  • find()：从字符串的左侧开始查找，返回子串首次出现的位置。
  • rfind()：从字符串的右侧开始查找，返回子串最后一次出现的位置。
  • 容错性：如果指定的子串不存在，它们不会报错，而是安全地返回 -1。

index()与 rindex()

  • index()：功能与 find() 类似，也是从左向右查找首次出现的位置。
  • rindex()：功能与 rfind() 类似，也是从右向左查找最后一次出现的位置。
  • 严格性：如果子串不存在，它们会抛出异常（ValueError），终止程序运行。通常在确定子串一定存在时使用。

count()

  • 用于统计一个子串在当前字符串中一共出现了多少次。
  • 它同样支持指定查找的范围，如果不指定，则默认统计整个字符串中的总数。

# find(), rfind(), index(), rindex(), count()
s = 'a,b,c,d,c,b,a'
print(s.find('a'))  # 返回首次出现的位置，即0
print(s.rfind('a'))  # 返回最后一次出现的位置，即12
print(s.find('z'))  # 找不到返回-1
print(s.rfind('z'))  # 找不到返回-1

print(s.index('a'))  # 返回首次出现的位置，即0
print(s.rindex('a'))  # 返回最后一次出现的位置，即12
print(s.index('z'))  # 找不到就报错
print(s.rindex('z'))  # 找不到就报错

print(s.count('a'))  # 返回2

字符串拆分

Python 中用于将字符串拆分成多个部分的方法主要分为两组：split 系列和 partition 系列。它们的核心区别在于拆分后的结果形式以及对分隔符的处理。

split() 与 rsplit()

这两个方法的作用是以指定字符为界，将字符串拆开，并返回一个包含所有片段的列表。

  • 方向不同：
    • split()：从左往右进行切割。
    • rsplit()：从右往左进行切割。
    • 注：在大多数常见情况下（如不限制切割次数），两者的结果是一致的。
  • 结果特点：
    • 切割后产生的是多个字符串片段。
    • 如果原字符串为空，返回空列表。
    • 可以通过参数 maxsplit 控制最大切割次数。

partition() 与 rpartition()

这两个方法同样是以指定字符为界，但拆分逻辑更严格，结果固定为3个部分的元组。

  • 方向不同：
    • partition()：从左往右找第一个匹配项进行切割。
    • rpartition()：从右往左找第一个匹配项进行切割。
  • 结果特点（强制三分割）：
    • 无论字符串多长，结果都包含 3个元素。
    • 格式固定为：(分隔符前的部分, 分隔符本身, 分隔符后的部分)。
  • 特殊情况：
    • 如果指定的分隔符不在原字符串中：
      • partition() 返回：(原字符串, '', '')
      • rpartition() 返回：('', '', 原字符串)

# split(), rsplit(), partition(), rpartition()
s = 'a,b,c,d,c,b,a'
print(s.split(','))  # ['a', 'b', 'c', 'd', 'c', 'b', 'a']
print(s.rsplit(','))  # ['a', 'b', 'c', 'd', 'c', 'b', 'a']
print(s.split())  # ['a,b,c,d,c,b,a'] 如果不传入分隔符，那么默认空白符即分隔符，比如' ','   '
print(s.split(',', maxsplit = 2))  # ['a', 'b', 'c,d,c,b,a']  # maxsplit指定最大分割次数

print(s.partition('c'))  # ('a,b,', 'c', ',d,c,b,a')
print(s.rpartition('c'))  # ('a,b,c,d,', 'c', ',b,a')

print(s.partition('e'))  # ('a,b,c,d,c,b,a', '', '')
print(s.rpartition('e'))  # ('', '', 'a,b,c,d,c,b,a')

字符串替换

Python 中主要提供三种方式进行字符串替换，分别适用于不同的场景：

replace()

最直观的替换方式，基于子串进行匹配，将指定的旧字符串整体替换为新字符串。支持通过参数限制最大替换次数。

1
2
3
4
5

# replace()
s1 = 'a,a'
print(s1)  # a,a
s2 = s1.replace('a','b')  # 用'b'代替'a'
print(s2)  # b,b

maketrans() 与 translate()

高效的字符级映射转换方案。

  • maketrans() 用于构建一张“翻译表”，定义字符之间的一一对应关系。
  • translate() 依据这张表对字符串中的字符进行批量转换。 这种方式特别适合处理多对多的字符替换或简单的字符加密。
1
2
3
4
5

# maketrans(),translate()
s1 = 'Now we need to take action'
table = ''.maketrans('Nowe','Yete')  # 建立规则 N-Y o-e w-t e-e
s2 = s1.translate(table)  # 按规则转义
print(s2)  # Yet te need te take actien

字符串调整

Python提供了一些函数用于调整字符串在指定宽度内的显示位置，或对字符串进行数字填充，使其达到特定的格式要求。

center()：将字符串居中放置在新字符串中。如果指定宽度大于原字符串长度，则在左右两侧使用指定字符（默认为空格）进行填充。 ljust()：将字符串左对齐放置在新字符串中。如果指定宽度大于原字符串长度，则在右侧使用指定字符（默认为空格）进行填充。 rjust()：将字符串右对齐放置在新字符串中。如果指定宽度大于原字符串长度，则在左侧使用指定字符（默认为空格）进行填充。 zfill()：专门用于左侧以字符 ‘0’ 进行填充，通常用于生成固定位数的数字字符串或补零对齐。

下面给出代码演示：

1
2

# center()、ljust()、rjust()、zfill()
s = 'Big Door'
print(s.center(20))  # 扩充长度为20，居中，空格填充  输出      Big Door      
print(s.center(20,'='))  # 扩充长度为20，居中，'='填充  输出======Big Door======
print(s.ljust(20,'='))  # 扩充长度为20，左对齐，'='填充  输出Big Door============
print(s.rjust(20,'='))  # 扩充长度为20，右对齐，'='填充  输出============Big Door
print(s.zfill(20))  # # 扩充长度为20，右对齐，'0'填充  输出000000000000Big Door
