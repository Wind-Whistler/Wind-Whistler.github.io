文件的类型

文件的定义

文件是数据的抽象和集合，是辅助存储器上的数据序列。

  • 存储状态：数据存放在硬盘中。
  • 占用状态：程序对文件进行独占性处理。

文件的两种类型

所有文件本质上均以二进制形式存储，仅展示方式不同。

文本文件

  • 定义：由单一特定编码（如UTF-8、GBK）组成的文件。
  • 本质：存储着的长字符串。
  • 适用：.txt、.py、.csv 等。

二进制文件

  • 定义：直接由比特0和1组成，没有统一的字符编码。
  • 本质：具有特定的文件格式（如PNG的图像压缩规则）。
  • 适用：.png、.avi、.exe、.zip 等。

核心区别

打开方式 代码 输出结果
文本模式 open("f.txt", "rt") 中国是个伟大的国家!
二进制模式 open("f.txt", "rb") b'\xd6\xd0\xb9\xfa...'

编码的作用

编码是字符与二进制之间的翻译规则。

  • 同字不同码：同一文本，使用不同编码，生成的二进制不同。
    • “哈”(UTF-8) → E5 93 88
    • “哈”(GBK) → B9 FE
  • 同码不同文：同一二进制，使用不同编码解码，得到的文本不同（乱码根源）。
