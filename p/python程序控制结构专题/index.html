条件表达式

关系运算符

关系运算符用于构建条件表达式，比较两个值之间的关系。Python 中的关系运算符包括：< (小于)，<= (小于等于)，>= (大于等于)，> (大于)，== (等于)，!= (不等于)。

一个显著特点是，Python 允许连续使用关系运算符，这不仅减少了代码量，也更符合人类的思维方式。此外，为避免错误，Python 语法不允许在条件表达式中使用赋值运算符 =，否则会抛出语法错误。

print(4 == 5  != 6)  # False

print(1 = 1)  # 报错

逻辑运算符

逻辑运算符用于组合多个条件表达式，Python 提供了以下三种：

  • x and y：逻辑与，当且仅当 x 和 y 都为真时，结果为真。
  • x or y：逻辑或，当 x 或 y 中至少有一个为真时，结果为真。
  • not x：逻辑非，对条件 x 的结果进行取反。

逻辑运算符 and 和 or 具有短路求值（或称惰性求值）的特点。这意味着 Python 在计算表达式时，并不会对所有子表达式进行求值，而是只计算必须计算的部分。例如，在 表达式1 and 表达式2 中，如果 表达式1 的值为 False，则整个表达式的值必定为 False，因此 Python 将不再计算 表达式2。利用这一特性可以优化程序性能。

分支结构

分支结构是程序根据条件判断来选择执行路径的控制结构。

分支结构类型

从简单到复杂，主要有四种形式：

  1. 单分支 (if)：只有条件为真时才执行特定代码。
  2. 二分支 (if-else)：条件为真走一条路，为假走另一条路。
  3. 多分支 (if-elif-else)：依次判断多个条件，执行第一个匹配的分支。
  4. 嵌套：在一个分支结构内部包含另一个分支结构。

# 单分支结构
if eval(input()) == 1:  # 字符串转数字
    print('Good!')
x = input()
a,b = map(int,x.split(','))  # 对x解包，并应用int函数
if a > b:
    a,b = b,a  # 交换数值
print(a,b)

# 二分支结构
if eval(input()) == 1:  # 字符串转数字
    print('Good!')
else:
    print('bad')

x = 1 if eval(input()) == 1 else 2  # 三元运算符
print(x)

# 多分支结构
ans = eval(input())
if ans == 1:  # 字符串转数字
    print('Good!')
elif ans == 2:
    print('Excellent!')
else:
    print('Bad~')

循环结构

Python的循环控制结构主要有两种形式：for循环和while循环。此外，还有几个特殊的控制语句可以改变循环的执行流程。

for循环

for循环通常用于循环次数可以提前确定的情况，或者用于遍历一个序列（如列表、字符串）中的所有元素。它会从一个可遍历的结构中逐个提取元素，放入循环变量中，并执行一次循环体内的语句块，直到遍历完所有元素。

while循环

while循环通常用于循环次数难以提前确定的情况。它根据一个条件来决定是否反复执行循环体内的语句。只要条件为真，循环就会一直执行下去，直到条件不再满足为止。

特殊控制语句

在循环中，可以使用以下语句来控制流程：

  • break: 立即跳出并结束当前整个循环，然后执行循环后面的代码。
  • continue: 结束当前这一次循环，直接跳到下一次循环的开始，继续执行后续的循环。
  • else: 可以与循环搭配使用。当循环因为条件不成立或遍历结束而正常结束时，会执行else子句中的代码块。但如果循环是因为执行了break语句而提前结束的，则不会执行else中的代码。

列表生成式

列表生成式是一种非常简洁的语法，能够在一行代码里快速创建新的列表。

它的基本语法结构是：[表达式 for 变量 in 可迭代对象 if 条件]

这个结构的执行过程如下：

  1. 遍历：从“可迭代对象”（如列表、字符串、元组等）中逐个取出元素，赋值给“变量”。
  2. 判断：如果存在 if 条件，则进行判断。只有满足条件的元素才会进行下一步。
  3. 生成：将满足条件的元素代入“表达式”进行计算，生成一个新的元素。
  4. 组合：将所有通过表达式计算出的新元素组合成一个列表。

其中，if 条件 和 for 循环 都是可选的。如果没有条件判断，生成的列表将包含可迭代对象中的所有元素。

下面给出代码示例：

3

l = [i for i in range(20) if i % 2 == 0]  #生成包含0-19所有偶数的列表
s = [i for i in 'Hello, World' if i.isupper()]  # 取出所有大写字母
a = [i ** 2 for i in range(10) if i % 2 == 0]  # 取出0-9偶数的平方
tup = [(x,y) for x in [1,2,3] for y in [4,5,6]]  # 生成⼀个列表，包含两个列表中的所有元素的组合
