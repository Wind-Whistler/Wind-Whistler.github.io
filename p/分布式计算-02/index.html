Ray基本操作流程

Ray 集群的启动与关闭

这是使用 Ray 的第一步，用于初始化分布式环境或关闭已有的集群连接。

  • ray.init()：启动 Ray 集群。在 Jupyter Notebook 或脚本开头调用，初始化分布式运行时环境。
  • ray.shutdown()：关闭 Ray 集群。释放资源，通常在程序结束时调用。
1
2
3

import ray
ray.init()  # num_cpus可设定启用cpu核数
ray.shutdown()

异步执行

Ray 的核心特性之一是异步非阻塞执行，这使得主程序无需等待耗时任务完成即可继续运行。

  • @ray.remote：装饰器，将普通的 Python 函数转换为远程函数（即 Ray 任务）。
  • .remote()：调用该方法会立即返回一个 ObjectRef（对象引用/取件码），而不会等待函数实际执行完毕。主程序会立刻继续执行下一行代码。

import time

# 定义一个远程任务
@ray.remote
def task_sleep():
    time.sleep(5)
    return "Task Done"

# 异步提交任务
# 代码会瞬间执行到这里，不会卡住等待5秒
task_ref = task_sleep.remote()
print("任务已提交，主程序继续运行...")

同步获取

虽然任务是异步执行的，但在需要使用结果时，必须通过同步阻塞的方式获取。

  • ray.get()：这是一个同步阻塞操作。
    • 如果任务已完成，立即返回结果。
    • 如果任务未完成，主程序会在这里卡住（阻塞），直到结果计算完成并返回。
    • 注意：如果在 .remote() 后立刻接 ray.get()，程序可能会退化为串行计算，失去并行意义。
1
2
3
4

# 获取结果（阻塞操作）
# 如果上面的任务还没睡完5秒，这里就会卡住等待
result = ray.get(task_ref)
print(result)  # 输出: Task Done

共享内存与零拷贝

为了解决大数据在节点间传输占用带宽的问题，Ray 提供了共享内存机制。

  • ray.put()：将大对象（如大型矩阵、数据集）放入分布式共享内存（Object Store）中。
  • ObjectRef 传递：传递 ray.put() 返回的引用 ID，而不是直接传递大数据本身。
  • 零拷贝：如果多个核心在同一物理节点上，它们可以直接读取同一块内存地址，无需复制数据，极大提升效率。

import numpy as np

# 假设有一个巨大的矩阵
large_matrix = np.random.rand(10000, 10000)

# 将大矩阵放入共享内存，返回引用ID
matrix_ref = ray.put(large_matrix)

# 定义一个使用该矩阵的任务
@ray.remote
def process_matrix(matrix_id):
    # 任务内部通过 ray.get 获取数据
    # 如果在同一节点，这是零拷贝读取
    data = ray.get(matrix_id)
    return data.sum()

# 提交任务，传递的是引用ID（很小），而不是巨大的矩阵
result_ref = process_matrix.remote(matrix_ref)
result = ray.get(result_ref)

Map-Reduce思想

利用上述特性可以实现经典的 Map-Reduce 模式：

  1. Map：通过循环调用 .remote() 分发大量子任务。
  2. Barrier：通过 ray.get(list_of_refs) 等待所有任务完成。
  3. Reduce：在主程序中汇总所有结果（如求平均值）。

集群操作

Ray 集群采用“头部节点 + 工作节点”的架构模式。头部节点是集群的“大脑”，负责管理和调度；工作节点是执行具体计算任务的“打工仔”。主程序（Driver）连接到头部节点，将任务分发给工作节点并行执行。

头部节点

头部节点是集群的“大脑”和“管理员”。

  • 主要职责：维护集群的整体状态，调度任务分配，运行控制面板（Dashboard），并接收主程序（Driver）的连接。
  • 设定方法：在作为管理员的机器上执行 ray start --head 命令。可以使用 --num-cpus 参数指定使用的 CPU 核心数。执行后会显示节点的 IP 地址和端口号，以及访问 Dashboard 的网址。

工作节点

工作节点是集群的“打工仔”，负责执行具体的计算任务。

  • 主要职责：接收头部节点派发的任务，执行计算，并将结果返回给头部节点。用户可以随时向集群增加或减少工作节点。
  • 设定方法：在作为计算节点的机器上执行 ray start --address=<头部节点IP>:<端口> 命令。需要填入头部节点的 IP 地址和端口号（通常在头部节点启动时的输出信息中显示），同样可以指定使用的 CPU 核心数。

配合流程

建立集群后，在 Python 代码中通过 ray.init() 连接集群（默认连接本地存在的集群，或手动指定地址）。主程序提交任务后，头部节点负责将任务调度到各个工作节点上并行执行。任务完成后，结果会汇总回头部节点。需要关闭节点时，在对应机器的命令行中执行 ray stop 即可。

data = np.random.poisson(lam = 5,size = 100000)
data_ref = ray.put(data)  # 存入共享内存减小通信成本

# 使用Bootstrap估计Possion分布平均值
# 定义远程函数
@ray.remote
def Ray_Bootstrap(data,seed):
    np.random.seed(seed)
    sample = np.random.choice(data,size = len(data),replace = True)
    return np.mean(sample)

from sklearn.datasets import make_classification
from sklearn.model_selection import KFold
from sklearn.svm import SVC
from sklearn.metrics import accuracy_score

X,y = make_classification(
    n_samples = 10000,
    n_classes = 2,
    n_features = 10,
    random_state = 123
)

C_values = [0.1,1,10]
gamma_values = [0.01,0.1,1]

K = 5

@ray.remote
def train_and_eval_fold(X_ref, y_ref, train_idx, val_idx, C, gamma):
    # 从共享内存中切片读取数据
    X_train, X_val = X_ref[train_idx], X_ref[val_idx]
    y_train, y_val = y_ref[train_idx], y_ref[val_idx]
    
    model = SVC(C=C, gamma=gamma)
    model.fit(X_train, y_train)
    preds = model.predict(X_val)
    return accuracy_score(y_val, preds)

kf = KFold(n_splits=K, shuffle=True, random_state=123)

X_id = ray.put(X)
y_id = ray.put(y)

# 将嵌套循环展开，收集所有的 ObjectRef 对象
tasks = []
params_list = []  # 用于记录每个 Task 对应的参数组合

for C in C_values:
    for gamma in gamma_values:
        for train_idx, val_idx in kf.split(X):
            # 发射任务：只传递数据 ID 和索引
            task = train_and_eval_fold.remote(X_id, y_id, train_idx, val_idx, C, gamma)
            tasks.append(task)
        params_list.append({"C": C, "gamma": gamma})

# 等待所有 M * K 个模型训练完毕
all_scores = ray.get(tasks)

# 汇总结果 (每 K 个结果算一个平均值)
best_score_ray = 0
best_params_ray = None

for i, params in enumerate(params_list):
    # 取出当前参数组合对应的 K 个 Fold 的分数
    fold_scores = all_scores[(i * K): (i + 1) * K]
    mean_score = np.mean(fold_scores)
    if mean_score > best_score_ray:
        best_score_ray = mean_score
        best_params_ray = params

print(f"最佳参数: {best_params_ray}, 准确率: {best_score_ray:.4f}")
# 结果：最佳参数: {'C': 1, 'gamma': 0.1}, 准确率: 0.9583
