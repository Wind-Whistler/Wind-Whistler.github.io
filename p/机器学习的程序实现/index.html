Sklearn简介

Scikit-learn（简称 sklearn）是一个基于 Python 的主流机器学习库，主要实现对机器学习模型的构建与训练，涵盖分类、回归、聚类这三类常见任务，并提供了相应的算法接口供开发者调用；它的核心数据结构是数值型的 Array 类型（如 NumPy 数组或 Pandas DataFrame），因此像 Apriori 这类基于事务型数据的关联规则挖掘算法，并不在其内置实现范围内。

import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
from sklearn.linear_model import LinearRegression

np.random.seed(123)

# 生成数据
X = np.random.normal(size = (1000, 3))
beta = np.array([1, 2, 3]).reshape(-1,1)
y = X @ beta + 4 + np.random.normal(size = (1000, 1)).reshape(-1,1)

数据分割

sklearn 提供的另一个十分实用的功能是数据集划分。在进行机器学习时，通常会将数据分为训练集和测试集。通过 sklearn 的 model_selection 模块，我们可以导入 train_test_split 函数对数据集进行划分。该函数提供了样本比例以及等比抽样（分层抽样）等有效参数，能够帮助我们实现个性化的操作。下面将对这一功能进行演示。

# sklearn.model_selection下包含了一系列对模型选择有帮助的函数
from sklearn.model_selection import train_test_split  # 这里是导入了一个函数
X = np.arange(12).reshape(6,2)
y = np.array([0,0,0,1,1,1])

print('3:1')
print(train_test_split(X,y,random_state=42))   # 默认按照0.25:0.75的比例
print('1:1') 
train_test_split(X,y,test_size=0.5,random_state=42)  # 也可以自己设置相关参数进行划分

数据预处理

sklearn 同样提供了强大的数据预处理功能，这些功能主要集成在preprocessing 模块下。通常而言，我们可以使用两类核心方法：数据的标准化与数据的归一化。标准化主要涉及纵向处理，常见的包括 Z-score 标准化以及 0-1 标准化；而归一化一般是以样本为单位进行处理，即对单个样本的所有特征除以它们的某一个范数，从而实现单个样本的归一化。下面将进行代码演示。

# z-score
from sklearn.preprocessing import StandardScaler, MinMaxScaler  # 导入标准化类
scalar = StandardScaler()  # 进行实例化
scalar.fit(X_train)  # 使用训练集去训练标准化评估器的参数
print(scalar.mean_)  # 输出每个特征维度的均值
print(scalar.scale_) # 输出每个特征维度的标准差

# 使用训练集的均值方差对训练集进行归一化
X_train_scaled = scalar.transform(X_train)
# 使用训练集的均值方差对测试集进行归一化(防止数据泄露)
X_test_scaled = scalar.transform(X_test)
print(X_train_scaled)
print(X_test_scaled)

# 0-1标准化
Minmax_scalar = MinMaxScaler()
Minmax_scalar.fit(X_train)
print(Minmax_scalar.data_max_)
print(Minmax_scalar.data_min_)

X_train_minmax = Minmax_scalar.transform(X_train)
X_test_minmax = Minmax_scalar.transform(X_test)
print(X_train_minmax)
print(X_test_minmax)

数据归一化

数据归一化的主要目的是在进行相似度衡量时，使结果更加客观，防止量纲差异对相似度测量产生较大影响。

from sklearn.preprocessing import Normalizer

X_train_norm = normalizer.fit_transform(X_train)  # 默认L2，可以自己设定L1
X_test_norm = normalizer.transform(X_test)
