Pytorch简介

PyTorch 是一个由 Meta开发的开源深度学习框架，主要用于搭建和训练各类 AI 模型。

它最大的同行是 Google 推出的 TensorFlow。相比 TensorFlow，PyTorch 的核心优势在于：

  • 极度灵活好上手：PyTorch 采用动态计算图，代码可以像普通 Python 程序一样逐行运行和调试，非常直观；而 TensorFlow 早期主打静态图，需要先定义完整流程再执行，调试相对繁琐。
  • Python原生风格：它的语法高度贴合 Python 和 NumPy，开发者几乎可以无缝切换，学习门槛极低。
  • 学术界主流：由于开发效率高，目前绝大多数前沿的 AI 论文和最新大模型都会首选在 PyTorch 上发布，拥有极其丰富的开源资源。

总结一下就是：TensorFlow 偏向工业级部署，而 PyTorch 胜在灵活、易调试，是目前研究探索和快速开发的首选工具。

张量Tensor

Tensor简介

在深度学习框架中，Tensor是最核心的数据结构。从表面上看，它可以被理解为一个多维数组：0维的 Tensor 是一个数字(标量)，1维是一串数字（向量），2维是一张表格（矩阵），更高维度的 Tensor 则可以用来表示彩色图片、视频或批量数据等复杂结构。它是神经网络中传递输入数据、存储模型权重以及计算梯度的基本载体。

Tensor 和 ndarray 的异同

相同点： 两者在本质和操作上高度相似。它们都是用来高效存储和操作大规模多维数值数据的数组；基本的运算逻辑非常接近，比如加减乘除、矩阵乘法、索引切片、形状变换以及广播机制等，写代码时的手感几乎一致；在实际开发中，两者可以非常方便地互相转换，通过 torch.from_numpy() 可以把 NumPy 数组转为 Tensor，通过 .numpy() 可以把 Tensor 转回 NumPy 数组。

不同点： 虽然长得像，但两者的设计目标和能力边界完全不同。NumPy 是通用的科学计算库，而 Tensor 是专为深度学习打造的专用工具。

最主要的区别在于硬件支持。NumPy 只能在 CPU 上运行；而 Tensor 原生支持 GPU 加速，在处理海量数据和大规模并行计算时，速度比 NumPy 快几十倍甚至上百倍。

其次是自动求导机制。这是两者最本质的区别，NumPy 只是一个纯粹的数值计算库，完全不支持自动求导；而 Tensor 内置了自动微分系统（Autograd），能够自动记录所有的运算过程并构建“计算图”，在训练 AI 模型时只需调用一个方法就能自动计算出梯度，极大地简化了反向传播的过程。

最后是设计定位与默认数据类型。NumPy 主要用于传统的数据分析、矩阵运算等通用科学计算，其默认数据类型通常是 float64；而 Tensor 是深度学习全流程的核心，为了适配 GPU 计算并节省显存，其默认数据类型通常是 float32。

广播机制

和Nunpy相同，Pytorch也具有数组广播的功能，合理运用数组广播可以有效减少计算量，提升代码运行效率，下面给出一段示例代码:

# 广播机制
vec = torch.tensor([1.0,2.0,3.0])
mat = torch.randn((3,3))
print(mat + vec)  # 这里vec和mat有相同的列数，所以会自动把vec加到mat的每一行
print(mat * vec)  # 乘法同理

vec = vec.reshape(3,1)
print(mat + vec)  # 这里vec和mat有相同的行数，所以会自动把vec加到mat的每一列
print(mat * vec)  # 乘法同理

对于一些特殊的矩阵类型，如对角矩阵，使用广播机制能显著降低时间复杂度。

统计分布

PyTorch分布模块

PyTorch 在生成分布时采用了“面向对象”的设计思路，而 NumPy 更偏向于直接调用的“面向过程”函数式写法。PyTorch 的核心逻辑是先实例化一个具体的分布类（Distribution Class），这个类就像一个封装好的数学模型对象，创建之后就可以在对象上反复调用各种方法。这种设计不仅实现了状态封装和接口统一，更重要的是能原生支持深度学习的计算图与自动求导（Autograd）。

常用操作：

  • .sample()：从该分布中采样出随机数。
  • .log_prob(value)：计算某个值的对数概率，在训练神经网络计算损失时非常常用。
  • .entropy()：计算分布的熵（衡量分布的不确定性）。

import torch.distributions as D
import math

norm = D.Normal(loc=torch.tensor([1.0]), scale=torch.tensor([math.sqrt(3.0)]))  # 实例化一个均值为3，标准差为3的正态分布

norm.log_prob(torch.tensor([1.0, 2.0, 3.0]))  # 计算概率密度函数的对数值
norm.sample(sample_shape=(5,))  # 从对应分布生成随机数

bern = D.Bernoulli(probs=torch.tensor([0.1, 0.5, 0.9]))  # 创建三个伯努利分布，输入三个参数
bern.sample()  # 默认取一组样本
bern.sample(sample_shape=(6,))  # 指定生成样本的形状

exp = D.Exponential(rate = 3)  # 实例化 lambda = 3 的指数分布
exp.sample(sample_shape = (5,5))  # 抽取样本
exp.log_prob(torch.tensor([2.0,3.0,4.0]))  # 取对数概率
