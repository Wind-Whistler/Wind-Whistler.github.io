图片结构简介

图片的存储结构

图片在计算机中以多维数组（张量）的形式存储。

单张图片：三维数组

维度 含义 说明
H (Height) 高度 竖直方向的像素数
W (Width) 宽度 水平方向的像素数
C (Channel) 通道 颜色分量数

数组的值：表示对应通道在该像素位置的强度。

彩色图 vs 灰度图

类型 形状 说明
彩色图 (RGB) [H, W, 3] 3个通道：红(R)、绿(G)、蓝(B)。
三通道强度叠加合成彩色。
灰度图 [H, W] 1个通道，仅表示亮度。

彩转灰

通过加权求和合并三个通道的强度：

$$Gray = 0.299R + 0.587G + 0.114B$$

扩展到深度学习

处理一批数据时，在最前面增加一个批量维度 N：

$$[N, H, W, C]$$

这也是CNN卷积层的标准输入格式。

import numpy as np
im_arr = np.array(im)  # 把PIL对象转换为Numpy数组
print(im_arr.shape)  # (2160, 3840, 3)

print("Red channel:\n")  # 输出红色通道
print(im_arr[:, :, 0])

print("\nGreen channel:\n")  # 输出绿色通道
print(im_arr[:, :, 1])

print("\nBlue channel:\n")  # 输出蓝色通道
print(im_arr[:, :, 2])

# 转灰色
im_grey = 0.2989 * im_arr[:, :, 0] + 0.5870 * im_arr[:, :, 1] + 0.1140 * im_arr[:, :, 2]  # 生成新层
print(im_grey.shape)  # (2160, 3840)

Image.fromarray(np.uint8(im_grey))  # 变回去 unit8是numpy的一种数据类型，表示无符号占8个二进制位的整数
