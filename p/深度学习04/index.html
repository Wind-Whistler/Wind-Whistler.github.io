图片结构简介

图片的存储结构

图片在计算机中以多维数组（张量）的形式存储。

单张图片：三维数组

维度 含义 说明
H (Height) 高度 竖直方向的像素数
W (Width) 宽度 水平方向的像素数
C (Channel) 通道 颜色分量数

数组的值：表示对应通道在该像素位置的强度。

彩色图 vs 灰度图

类型 形状 说明
彩色图 (RGB) [H, W, 3] 3个通道：红(R)、绿(G)、蓝(B)。
三通道强度叠加合成彩色。
灰度图 [H, W] 1个通道，仅表示亮度。

彩转灰

通过加权求和合并三个通道的强度：

$$Gray = 0.299R + 0.587G + 0.114B$$

扩展到深度学习

处理一批数据时，在最前面增加一个批量维度 N：

$$[N, H, W, C]$$

这也是CNN卷积层的标准输入格式。

卷积

为什么要卷积

直接对图像使用全连接层（MLP）存在明显缺陷：将二维图像展平会破坏像素间的空间邻接关系，且全连接带来参数爆炸，导致模型极易过拟合。为解决这些问题，卷积神经网络引入了局部感受野与参数共享两大归纳偏置。

怎么卷积

卷积的操作逻辑非常直观：使用一个较小的卷积核（如 3×3）作为特征提取器，在输入图像上逐格滑动。在每个窗口位置，卷积核与对应像素做乘加运算，最终生成一张特征图。值得注意的是，深度学习中的“卷积”实际上是数学上的互相关（未进行核翻转），但由于权重通过数据学习，这并不影响模型表达能力。

单靠卷积不足以完成任务，实际应用中通常配合汇聚（Pooling）层（如最大汇聚或平均汇聚）进行降维，在减少计算量的同时增强模型对微小位移的鲁棒性。此外，卷积层有三个关键超参数需设定：核大小（决定感受野）、步幅（控制滑动步长，大于1时起到降采样作用）以及填充（边缘补零以维持尺寸）。输出特征图的尺寸遵循公式：$W_{out}=\lfloor (W_{in}-K+2P)/S \rfloor +1$。

在处理彩色图像或多层堆叠时，通道数至关重要：若输入通道为 $C_{in}$，输出通道为 $C_{out}$，则需要 $C_{in} \times C_{out}$ 个卷积核，每个输出通道代表一种特定的抽象特征（如边缘或纹理）。随着网络加深，特征会从浅层的边缘逐步组合为深层的语义概念。从 LeNet 奠定基础，到 AlexNet 引入 ReLU 与 Dropout，再到 VGG 验证小卷积核堆叠的有效性，直至 ResNet 通过残差连接解决深层网络退化问题，CNN 的演进始终围绕着提升特征提取效率与优化稳定性展开。

卷积的好处

卷积的核心优势在于极高的参数效率：无论输入图像多大，可学习参数仅存在于微小的卷积核中，避免了全连接层的冗余，使得深层网络在图像任务上的训练成为可能。

池化

池化的核心作用是降维与信息压缩。在连续的卷积层之间加入池化（通常为 2×2 窗口），可以将特征图的尺寸减半，在显著降低计算量的同时，赋予模型对微小位移的平移不变性（即目标稍微移动不影响识别结果）。最常见的实现是最大池化，即只保留窗口内最强烈的响应值。

随着网络不断进行“卷积 → 池化”的堆叠，特征图会发生质变：空间尺寸（宽高）逐渐缩小，而通道数（特征种类）逐渐增加。原始像素最终会被转化为 7×7×512 这类极小空间尺寸、极高通道维度的特征张量。此时，特征已不再是可视的图像，而是高度抽象的语义证据。

最终的图像识别通过特征聚合完成：传统做法是将特征拉平为一维向量接入全连接层；现代网络则常用全局平均池化直接将空间压缩，输出一个类别向量。至此，池化完成了从“像素空间”到“语义向量”的转换。

CNN结构

CNN 是一类模型的统称，而非单一模型。 其核心定义在于：只要网络架构中大量使用了“卷积核”进行特征提取，这类模型都属于 CNN 家族。 相比于全连接层，卷积核带来的参数共享和局部感受野是其区别于其他网络的根本特征。

在 CNN 这一大类下，包含多种经典的具体架构：

  • LeNet-5：早期奠基之作，确立了基础结构。
  • AlexNet / VGG / ResNet：后续演进的重要模型，特别是 ResNet 引入的残差连接解决了深层网络的退化问题。

通用的 CNN 工作流程如下：

  1. 特征提取阶段：通常采用 “卷积 $\rightarrow$ 池化 $\rightarrow$ 卷积 $\rightarrow$ 池化” 的循环堆叠结构。通过反复压缩空间尺寸（宽高）并增加通道数（特征种类），将原始像素转化为高度抽象的语义特征。
  2. 分类/预测阶段：当特征图被压缩至较小尺寸（如 7×7）且通道数极大时，空间位置关系已不再重要。此时将特征图拉平（Flatten）为一维向量，接入全连接层（MLP），最终输出分类概率或回归值。

import torch.nn as nn
class CNN(nn.Module):
    def __init__(self):
        super().__init__()
        self.conv1 = nn.Conv2d(in_channels = 1, out_channels = 20, kernel_size = 5, stride = 2)  # in_channels 输入通道 # out_channels 输出通道 kernel_size 卷积核大小 stride 步长
        self.ac1 = nn.ReLU()  # 激活函数提高复杂度
        self.pool1 = nn.MaxPool2d(kernel_size = 2)  # 池化层对特征图进行缩略
        self.fc1 = nn.Linear(in_features = 720, out_features = 10)  # 线性层作MLP
    
    def forward(self,x):
        x = self.conv1(x)  # 卷积
        x = self.ac1(x)  # 激活
        x = self.pool1(x)  # 池化
        x = self.fc1(torch.flatten(x,start_dim = 1))  # 注意设置start_dim = 1再拉平，因为dim0代表样本序号
        x = nn.functional.softmax(x,dim = 1)  # 算一个softmax
        return x

num_epoch = 30
LOSS = []
for epoch in range(num_epoch):
    L = []
    for X_batch, y_batch in loader:
        y_pred = model(X_batch)
        loss = criterion(torch.log(y_pred),y_batch)  # NLLLoss 要求输入的是对数概率，个人不是很喜欢NLLLoss，因为容易数字不稳定然后爆炸
        L.append(loss.item())
        optimizer.zero_grad()
        loss.backward()
        optimizer.step()
    LOSS.append(np.mean(np.array(L)))
    if (epoch + 1) % 5 == 0:
        print(f'Epoch:{epoch + 1}, loss:{LOSS[epoch]}')
