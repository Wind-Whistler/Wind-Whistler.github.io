任务介绍

这一期任务的核心是让计算机学会“看懂”中文名字背后的性别倾向。具体来说，输入是一个任意长度的中文姓名（比如“张伟”、“王芳”、“李雪婷”），输出是一个二元判断——男性还是女性。

任务的关键难点在于：中文名字的性别信息不是靠单个字决定的，而是靠字与字的组合和顺序共同表达的。 比如“刘强”和“刘娜”，第一个字相同，但第二个字直接把性别倾向完全扭转；“陈雪”和“雪陈”字完全相同，但顺序不同给人的感觉也完全不同。有些字性别指向性很强（“刚”“磊”几乎全是男性，“娟”“婷”几乎全是女性），但更多字是中性的，需要结合上下文才能判断（比如“超”在“李超”里是男性，在“杨超男”里又变成了女性暗示）。

此外，名字长度不固定——有人两个字，有人三个字，甚至四个字，模型需要能够处理变长输入。还要考虑一些特殊情况：有的名字直接用“男”“女”字（如“陈男”“赵女”），有的名字借用自然景物或抽象词汇（如“林风”“云霞”），这些都需要模型从大量数据中自动学习规律。

总之，这个任务本质上是从汉字序列中提取性别相关的语义特征，并对这些特征进行加权综合，最终做出二分类决策。

整体思路

Step1：数据读取与筛选

读取名字数据后，统计所有汉字的出现频率。由于低频字（仅出现几次的冷僻字）会增加噪音且不利于模型学习，因此只保留高频字，丢弃低频字。这样做既能减少噪音，也能降低后续计算量。

Step2：One-hot 编码

用筛选出的高频字构建一个"词典"。假设选了 500 个高频字，则每个字对应一个长度为 500 的 One-hot 向量（该字对应位置为 1，其余为 0）。随后对每个名字样本逐字查字典，将名字转换为一系列向量。例如一个三字姓名，会变成 3 个长度为 500 的向量，堆叠成一个张量作为模型的输入。

Step3：搭建 RNN 模型

定义一个 RNN 网络结构，核心操作有两个：

  1. 逐字将 One-hot 向量输入模型
  2. 每输入一个字，RNN 结合"当前字的信息"和"之前积累的记忆"，更新内部状态

读完最后一个字后，用最终的内部状态预测性别，输出一个 0 到 1 之间的概率值。

Step4：训练模型

将已标注性别的数据（名字 + 对应性别）喂给模型。每次预测后，对比预测结果与真实标签，计算误差（Loss），再通过反向传播调整网络参数。重复此过程直至误差收敛到足够小。

Step5：预测

训练完成后，模型已学会从名字推断性别的规律。此时输入一个全新的、未见过的名字，模型即可输出性别预测结果及其置信度。

# 过滤掉未知类别
df = df[df.sex != "未知"]
names = df["dict"].values

# 计算单字频率

# 1. 将每个姓名拆分成单个字符的列表
#    例如："张三" -> ["张", "三"]
chars = [list(name) for name in names]

# 2. 将所有姓名的字符列表合并成一个扁平的大列表
#    itertools.chain(*chars) 把多个小列表"链"在一起
#    例如：[["张","三"], ["李","四"]] -> ["张","三","李","四"]
chars_flatten = list(itertools.chain(*chars))

# 3. 统计每个字符出现的次数
#    Counter 返回一个字典，键是字符，值是出现次数
freq = collections.Counter(chars_flatten)

# 4. 将统计结果转换成 DataFrame，两列分别是"字符"和"频次"
freq = pd.DataFrame(freq.items(), columns=["char", "freq"])

# 5. 按照频次从高到低排序
freq = freq.sort_values(by="freq", ascending=False)

dict_size = 500
dict = list(freq["char"].values[:dict_size])
dict_set = set(dict)
filtered = list(filter(lambda item: set(item[1]).issubset(dict_set), enumerate(names)))  # 获取高频词名字集合
ind = [idx for idx, name in filtered]  # 获取高频词名字索引
dat = df.iloc[ind]  # 获取高频词名字所有信息

# One-hot 编码
def char2index(char):
    return dict.index(char)  # 这里返回char在dict中的索引位置

def name2index(name):
    return [char2index(char) for char in name]  # 返回name的索引列表

def name2tensor(name):
    tensor = torch.zeros(len(name), 1, dict_size)  # 1个字符一个向量，中间的1表示batch_size，dict_size表示向量长度
    for i, char in enumerate(name):
        tensor[i, 0, char2index(char)] = 1
    return tensor

# 建立模型
class RNN(nn.Module):
    def __init__(self, input_size, hidden_size):
        super(RNN, self).__init__()
        self.hidden_size = hidden_size
        self.i2h = nn.Linear(input_size + hidden_size, hidden_size)
        self.h2o = nn.Linear(hidden_size, 1)

    def forward(self, input, hidden):
        combined = torch.cat((input, hidden), dim=1)  # 拼接过去隐藏层和当前输入
        hidden = torch.tanh(self.i2h(combined))  # 计算新的隐藏层
        output = torch.sigmoid(self.h2o(hidden))  # 输出
        return output, hidden

    def init_hidden(self): # 初始化隐藏层
        return torch.zeros(1, self.hidden_size)

# 正式模型训练
np.random.seed(123)
torch.random.manual_seed(123)

n = train.shape[0]
n_hidden = 64
nepoch = 5
bs = 100

rnn = RNN(dict_size, n_hidden)  # 实例化RNN模型需要两个参数，输入大小和隐藏层大小
opt = torch.optim.Adam(rnn.parameters(), lr=0.001)
train_ind = np.arange(n)
losses = []

for k in range(nepoch):
    np.random.shuffle(train_ind)
    # Mini-batch 循环
    for j in range(0, n, bs):  # 起始值 终止值 步长
        # 建立 mini-batch
        mb = train.iloc[train_ind[j:(j + bs)]]
        mb_size = mb.shape[0]
        loss = 0.0
        # 对 Mini-batch 中的每个名字进行循环
        for i in range(mb_size):
            name = mb["dict"].values[i]
            input = name2tensor(name)
            hidden = rnn.init_hidden()
            y = mb["y"].values[i]
            # 对名字中的每个字进行循环
            for s in range(input.shape[0]):
                output, hidden = rnn(input[s], hidden)
            loss = loss - y * torch.log(output) - (1.0 - y) * torch.log(1.0 - output)  # 只计算最后一个损失

        loss = loss / mb_size
        opt.zero_grad()
        loss.backward()
        opt.step()

        losses.append(loss.item())
        if j // bs % 10 == 0:
            print(f"epoch {k}, batch {j // bs}, loss = {loss.item()}")

# 对测试集预测
ntest = test.shape[0]
true_label = test["y"].values
pred = np.zeros(ntest)
rnn.eval()
for i in range(ntest):
    input = name2tensor(test["dict"].values[i])
    hidden = rnn.init_hidden()
    with torch.no_grad():
        for s in range(input.shape[0]):
            output, hidden = rnn(input[s], hidden)
    pred[i] = output.item()
    if i % 100 == 0:
        print(f"processed {i}")
loss = -np.mean(true_label * np.log(pred) + (1.0 - true_label) * np.log(1.0 - pred))  # 交叉熵损失
print(loss)
pred_label = (pred > 0.5).astype(int)
print(np.mean(pred_label == true_label))  # 输出正确率
