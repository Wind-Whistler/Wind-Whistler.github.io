深度学习第 14 讲：注意力机制与 Transformer

一、注意力机制（Attention Mechanism）

1. 核心直觉

  • 人类视觉系统在处理海量信息时，会聚焦于最重要的部分。注意力机制模仿了这一过程。
  • Query-Key 比喻：
    • Query（查询）：代表我们想找的目标。
    • Key（键）：代表环境中各元素的标识。
    • 当 Query 与某个 Key 匹配时，注意力就聚焦到该位置。

2. 在机器翻译中的应用（早期经典）

  • 解决了传统 Seq2Seq 模型将源句压缩成固定长度向量带来的信息瓶颈问题。
  • 核心机制：在生成每个目标词 $y_t$ 时，动态地"关注"源句中相关的部分。
  • 数学表达：
    • 生成概率： $$p(y_t | y_1,...,y_{t-1}, x) = g(y_{t-1}, s_t, c_t)$$
      • $y_t$：当前输出的词
      • $s_t$：解码器的当前隐藏状态
      • $c_t$：当前时刻的上下文向量，是注意力机制的关键。
    • 上下文向量 $c_t$ 的计算：
      • $c_t$ 是输入序列所有隐藏状态的加权平均： $$c_t = \sum_i \alpha_{t,i} h_i$$
      • 注意力权重 $\alpha_{t,i}$：衡量第 $i$ 个输入词对生成当前输出词的重要性。
      • $$\alpha_{t,i} = \text{Softmax}(e_{t,i})$$
      • $$e_{t,i} = a(s_{t-1}, h_i)$$是一个打分函数，其参数数量固定，与输入序列长度无关。

3. 常见的打分函数

  • 加性模型： $$s(x, q) = v^\top \tanh(Wx + Uq)$$
  • 点积模型： $$s(x, q) = x^\top P q$$
  • 缩放点积模型： $$s(x, q) = x^\top q / \sqrt{D}$$（$D$是维度）
  • 双线性模型： $$s(x, q) = x^\top W q$$

二、自注意力机制（Self-Attention）

1. QKV 模式

  • 注意力机制被抽象为三个角色：
    • Query（Q）：“我想关注什么？”
    • Key（K）：“我有什么信息？”
    • Value（V）：“我提供什么内容？”
  • 注意力权重由 Query 和 Key 的相似度计算得出，然后用此权重对 Value 进行加权求和。

2. 自注意力定义

  • 当 $Q$, $K$, $V$ 都来自同一个输入序列 $X$ 时，即为自注意力。
  • 意义：让序列内部的每个元素都能与其他所有元素建立依赖关系，实现真正的"上下文理解"。它建立了序列中所有位置对的高阶结构。

3. 与传统模型的对比

  • RNN/CNN：主要利用局部信息，难以捕捉长距离依赖。
  • MLP：可以跨越长距离，但参数数量随输入长度变化。
  • 自注意力：是一种特殊的全连接层，其权重由内容（注意力）动态生成，参数数量固定，实现了连接模式与参数数量的解耦。

4. 缩放点积注意力公式

  • 映射：

    $$Q = X W_Q$$

    $$K = X W_K$$

    $$V = X W_V$$

  • 计算：

    $$\text{Attn}(Q, K, V) = \text{Softmax}\left(\frac{QK^\top}{\sqrt{d_k}}\right) V$$

    其中 $\sqrt{d_k}$ 是缩放因子，防止点积结果过大导致 Softmax 梯度消失。

三、Transformer

1. 概述

  • 2017 年由论文《Attention is All You Need》提出，完全基于注意力机制的网络结构。
  • 已成为现代大语言模型（LLM）的基本构成单位。

2. 架构类型

  • Encoder-Decoder（原始版）：编码器提取信息，解码器生成结果。
  • Decoder-only（主流）：专为自回归语言生成任务设计（如 GPT 系列）。本课重点介绍。

3. Decoder-only Transformer 工作流程

  1. 输入序列经过多个 Transformer 块，计算每个位置的隐藏表示。
  2. 用最后一个位置的表示来预测下一个词元。
  3. 将新词元加入序列，重复上述过程。

4. 构建 Transformer 块的核心组件

  1. 自注意力（Self-Attention）：通常是多头注意力（Multi-Head Attention），让模型从不同子空间学习信息。
  2. 前馈网络（FFN）：对每个位置的表示进行非线性变换，增加模型容量。
  3. 残差连接（Residual Connection）：缓解梯度消失，让网络学习"增量"，支持更深网络。
  4. 层归一化（Layer Normalization）：稳定训练过程，对序列长度变化不敏感。

典型结构如下：

$$X' = \text{LayerNorm}(X + \text{Attention}(X))$$

$$X'' = \text{LayerNorm}(X' + \text{FFN}(X'))$$

5. 解决的两个关键问题

  • 问题 1：缺乏位置信息

    • 自注意力是置换等变的，无法感知词的顺序。
    • 解决方案：位置编码（Positional Encoding）
      • 绝对位置编码：如正弦/余弦函数、可学习的向量。
      • 相对位置编码：关注位置间的相对距离。

  • 问题 2：破坏因果性

    • 在预测 $w_t$ 时，不能"偷看"未来的词 $w_{t+1}$。
    • 解决方案：因果掩码（Causal Mask）
      • 在计算注意力分数时，将对未来位置的分数设为 $-\infty$，使 Softmax 后的权重为 0。
      • $$A_{ij} = \begin{cases} Q_i K_j^\top / \sqrt{d_k}, & \text{若 } j \le i \\ -\infty, & \text{否则} \end{cases}$$

6. 完整图景（Decoder-only）

  1. 输入表示：词嵌入（Content Embedding）+ 位置编码（Positional Encoding）
  2. 多层 Transformer 块：
    • 带因果掩码的多头自注意力
    • 前馈网络
    • 残差连接 & 层归一化
  3. 输出投影：将最后一层最后一个位置的表示映射为下一个词的概率分布。

7. 成功原因

  • 架构优势：

    • 任意距离的直接交互，理论上支持长序列。
    • 易于堆叠和扩展参数量。

  • 实践优势：

    • 训练阶段可并行计算，对 GPU 友好。
    • 在大规模数据上表现卓越，已被广泛验证。
