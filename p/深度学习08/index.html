语言建模的两条“公理”

公理1：语言的生成是随机的，其内容具有统计学规律。

公理2：语言的基本单元按照自回归的形式生成。

核心推论：结合公理1和公理2，利用概率链式法则，序列生成问题转化为逐词元预测问题：

$$p(y_1, y_2, \ldots, y_m \mid x) = \prod_{i=1}^m p(y_i \mid x, y_1, \ldots, y_{i-1})$$

现代语言建模核心任务：下一词元预测，即建模 \( p(w_{t+1} \mid w_1, \ldots, w_t) \)。

序列数据的统计建模

核心矛盾：需要建模的条件概率 \( p(w_{t+1} \mid w_1, \ldots, w_t) \) 中，上下文 \( t \) 可以是任意长度，但模型的参数数量必须固定有限。

n-gram 模型

方法：引入马尔可夫假设，假设一个词只依赖于前面有限的 \( n-1 \) 个词。

$$p(w_t \mid w_1, \ldots, w_{t-1}) \approx p(w_t \mid w_{t-n+1}, \ldots, w_{t-1})$$

参数估计：直接通过计数获得。

$$\hat{p}(w_t \mid w_{t-n+1}, \ldots, w_{t-1}) = \frac{\text{count}(w_{t-n+1}, \ldots, w_t)}{\text{count}(w_{t-n+1}, \ldots, w_{t-1})}$$

问题：数据稀疏性。词汇量 10,000 时，n=2 的组合数为 1 亿，n=3 时为 1 万亿，大部分组合在训练集中从未出现。需引入平滑技术（加一平滑、回退、插值）来处理零概率问题。

本质：非参数方法，每个 n-gram 独立估计，缺乏泛化能力。

经典时间序列模型（VAR）

方法：向量自回归模型，假设当前值是过去 \( p \) 个值的线性组合加噪声。

$$Y_t = c + A_1 Y_{t-1} + A_2 Y_{t-2} + \cdots + A_p Y_{t-p} + \varepsilon_t$$

本质：这是一个参数化版本的 (p+1)-gram 模型。若假设 \( \varepsilon_t \sim N(0, \sigma^2 I) \)，则条件分布为：

$$Y_t \mid Y_{t-p}, \ldots, Y_{t-1} \sim N(c + A_1 Y_{t-1} + \cdots + A_p Y_{t-p}, \sigma^2 I)$$

启示：VAR 的限制在于线性结构。若将线性函数替换为参数化的非线性函数（如神经网络），即可克服缺陷。这正是 Bengio 2003 年工作的核心思路。

神经概率语言模型（Bengio, 2003）

方法：使用前馈神经网络进行非线性建模，但仍采用固定窗宽的 n-gram 假设。

关键创新：引入词嵌入，将每个词元映射为稠密向量，所有词嵌入构成一个可学习的参数矩阵。

输出：神经网络的输出经 Softmax 变换后得到词表上的概率分布。

贡献：证明神经网络在语言建模中的潜力，词嵌入思想沿用至今。

不足：仍是“暴力”截断序列，无法让 \( w_t \) 直接依赖过去所有元素。

循环神经网络（RNN）

方法：维护一个隐藏状态 \( h_t \)，汇总整个历史的信息。

$$h_t = f(W_{hh} h_{t-1} + W_{xh} w_t + b)$$$$p(w_{t+1} \mid \text{历史}) = g(W_{hy} h_t)$$

思维突破：用固定参数处理任意长度序列，实现参数共享，理论上支持长序列建模。

改进（LSTM/GRU）：引入门控机制（输入门、遗忘门、输出门），让模型能选择性地记住重要信息、忽略噪声，缓解梯度消失问题。

仍存在的问题：

  1. 顺序处理导致无法并行计算，训练速度慢。
  2. 长程依赖仍然困难，信息随距离衰减。
  3. 隐藏状态维度固定，但不同时刻需要记忆的信息量差异很大。
  4. 缺乏显式的上下文关注机制，依赖强度是隐式学习的。

# Prepare data
dict_size = 50
charset_size = dict_size + 1  # for EOS 注意这一点
dict = list(freq["char"].values[:dict_size])
dict_set = set(dict)
dat = list(filter(lambda name: set(name).issubset(dict_set), names))

# One-hot encoding
def char2index(char):
    return dict.index(char)

def name2index(name):
    return [char2index(char) for char in name]

def char2tensor(char):
    tensor = torch.zeros(1, charset_size)
    tensor[0, char2index(char)] = 1
    return tensor

def name2tensor(name):
    tensor = torch.zeros(len(name), 1, charset_size)
    for i, char in enumerate(name):
        tensor[i, 0, char2index(char)] = 1
    return tensor

def names2tensor(names):
    n = len(names)
    lens = [len(name) for name in names]
    max_len = np.max(lens)
    tensor = torch.zeros(max_len, n, charset_size)
    target = torch.zeros(max_len, n, dtype=int) + charset_size - 1
    for i in range(n):
        name = names[i]             # the i-th name
        for j in range(len(name)):  # the j-th character in the name
            tensor[j, i, char2index(name[j])] = 1
            if j < len(name) - 1:
                target[j, i] = char2index(name[j + 1])
    return tensor, np.array(lens), target

# Build model
class RNN(nn.Module):
    def __init__(self, input_size, hidden_size):
        super(RNN, self).__init__()
        self.hidden_size = hidden_size
        self.i2h = nn.Linear(input_size + hidden_size, hidden_size)
        self.i2o = nn.Linear(input_size + hidden_size, input_size)
        self.o2o = nn.Linear(hidden_size + input_size, input_size)
        self.dropout = nn.Dropout(0.1)
        self.logsoftmax = nn.LogSoftmax(dim=1)

    def forward(self, input, hidden):
        input_combined = torch.cat((input, hidden), 1)  
        hidden = torch.relu(self.i2h(input_combined))
        output = torch.relu(self.i2o(input_combined))  # 初步output
        output_combined = torch.cat((hidden, output), 1)
        output = self.o2o(output_combined)  # output再更新
        output = self.dropout(output)  # Dropout 层，概率设为 0.1。在训练时随机将 10% 的神经元输出置为 0，防止过拟合。在推理时不起作用。形状不变
        output = self.logsoftmax(output)  # 先用 Softmax 将它们转为概率分布, 再取对数
        return output, hidden

    def init_hidden(self, batch_size):
        return torch.zeros(batch_size, self.hidden_size)

n_hidden = 64
rnn = RNN(charset_size, n_hidden)

np.random.seed(123)
torch.random.manual_seed(123)
# device = torch.device("cuda")
device = torch.device("cpu")  # If no GPU on the machine

# train_id = np.random.choice(len(dat), 10000)
# train = [dat[i] for i in train_id]
train = dat

n = len(train)
n_hidden = 256
nepoch = 100
bs = 256

rnn = RNN(charset_size, n_hidden)
rnn = rnn.to(device=device)
opt = torch.optim.Adam(rnn.parameters(), lr=0.001)
train_ind = np.arange(n)
lossfn = nn.NLLLoss(reduction="none")
losses = []

t1 = time.time()
for k in range(nepoch):
    np.random.shuffle(train_ind)  # 打乱序号
    # Update on mini-batches
    for j in range(0, n, bs):
        # Create mini-batch
        ind = train_ind[j:(j + bs)]  # 抽取随机序号
        mb = [train[i] for i in ind]  # 根据抽取的序号获取样本
        mb_size = len(mb)  # 批量大小
        input, actual_len, target = names2tensor(mb)  # 获取输入张量、实际长度和目标张量
        input = input.to(device=device)
        target = target.to(device=device)
        max_len = input.shape[0]
        hidden = rnn.init_hidden(mb_size).to(device=device)
        loss = 0.0
        for s in range(max_len):
            output, hidden = rnn(input[s], hidden)  
            loss_s = lossfn(output, target[s])  # 这里要计算每一个字符的损失
            valid = torch.tensor((s < actual_len).astype(int)).to(device=device)  # 如果当前长度小于实际长度，则为有效字符，否则为无效字符
            loss = loss + loss_s * valid
        loss = torch.mean(loss / torch.tensor(actual_len).to(device=device))

        opt.zero_grad()
        loss.backward()
        opt.step()

        losses.append(loss.item())
        if j // bs % 10 == 0:
            print(f"epoch {k}, batch {j // bs}, loss = {loss.item()}")
plt.plot(losses)

family_names = np.unique([name[0] for name in dat])
def random_family_name():
    return np.random.choice(family_names, 1)[0]

def random_name(max_len=4):
    rnn.eval()  # 有dropout层时，推理时要设置为eval模式，否则会随机丢弃一些神经元，导致输出不稳定
    family_name = random_family_name()
    input = char2tensor(family_name).to(device=device)
    char_ind = [torch.argmax(input).item()]
    hidden = rnn.init_hidden(batch_size=1).to(device=device)
    for i in range(max_len - 1):
        output, hidden = rnn(input, hidden)
        ind = torch.argmax(output).item()
        if ind == charset_size - 1:
            break
        char_ind.append(ind)
        input.zero_()
        input[0, ind] = 1.0
    return char_ind

np.random.seed(123)
