为何引入注意力机制

RNN局限

在Transformer出现之前，循环神经网络（RNN）是处理序列数据的主流方法。但它存在一个根本性的缺陷：

  • 信息瓶颈：RNN需要将整个输入序列（比如一句话）压缩成一个固定长度的向量（最后一个隐藏状态），才能开始生成输出（比如翻译）。当输入序列很长时，这个固定长度的向量无法承载全部信息，导致早期的重要信息丢失。
  • 难以并行：RNN的计算是串行的，必须等前一个词处理完才能处理后一个词，这使得它在GPU上的训练效率较低。

注意力机制的核心思想：不再试图将整个输入压缩成一个向量，而是在生成每一个输出词时，都能“回头”去看一遍整个输入序列，并动态地决定哪些输入词更重要。

注意力机制雏形

以下介绍注意力机制的早期经典形式，主要用于机器翻译。

  1. 核心概念：

    • Query (查询)：当前解码器的状态 s_{t-1}，代表“我现在想翻译什么”。
    • Key (键)：编码器中每个输入词的隐藏状态 h_i，代表“我（这个词）有什么信息”。
    • Value (值)：同样也是编码器的隐藏状态 h_i，代表“我（这个词）的实际内容”。

  2. 工作流程：

    • 计算权重：计算Query和每个Key的匹配程度，得到一个分数 e_{t,i}。 $$e_{t,i} = a(s_{t-1}, h_i)$$ 其中 a() 是一个打分函数，其参数数量固定，不随输入序列长度改变。
    • 归一化：对这些分数进行Softmax操作，得到最终的注意力权重 α_{t,i}。 $$\alpha_{t, i} = \frac{\exp(e_{t, i})}{\sum_{j=1}^{T}\exp(e_{t, j})}$$
    • 加权求和：用这些权重对所有Value进行加权平均，得到当前时刻的上下文向量 c_t。 $$c_t = \sum_{i=1}^T \alpha_{t,i} h_i$$

  3. 常见打分函数：

    • 加性模型：s(x,q) = v^T tanh(Wx + Uq)
    • 点积模型：s(x,q) = x^T q
    • 缩放点积模型：s(x,q) = (x^T q) / sqrt(D) （Transformer中使用）

自注意力

上述注意力机制发生在编码器和解码器之间。而自注意力则更进一步，让序列自己和自己做注意力计算。

  • 定义：当Query、Key、Value都来自同一个输入序列时，就是自注意力。
  • 作用：它允许序列中的每个词，都能直接与序列中的所有其他词建立联系，从而捕捉长距离的依赖关系，实现真正的“上下文理解”。

Scaled Dot-Product Attention

这是Transformer中最核心的注意力计算公式。

  1. QKV模式： 输入序列 X 通过三个不同的权重矩阵进行线性变换，得到Q、K、V：

    $$Q = X W_Q, \quad K = X W_K, \quad V = X W_V$$

  2. 核心公式：

    $$ \text{Attention}(Q, K, V) = \text{Softmax}\left(\frac{Q K^T}{\sqrt{d_k}}\right) V $$
    • Q (Query)：N x d_k 矩阵
    • K (Key)：N x d_k 矩阵
    • V (Value)：N x d_v 矩阵
    • N：序列长度
    • d_k：Query和Key的维度
    • 除以 √d_k：防止点积结果过大，导致Softmax梯度消失。

  3. 直观理解：

    • Q K^T：计算一个N x N的相似度矩阵（也叫注意力矩阵）。
    • Softmax：对相似度矩阵的每一行进行归一化，让每一行的权重之和为1。
    • 乘以 V：根据权重，将所有Value进行加权求和，得到最终的输出。这个过程相当于用相似度矩阵对V进行了一次“更新”。

多头注意力

为了从不同的角度捕捉信息，Transformer使用了多头注意力。

  • 原理：不使用单一的 Q、K、V 集合，而是将它们分别通过多个不同的线性变换，得到多组 Q_i, K_i, V_i。
  • 过程：
    1. 对每组 Q_i, K_i, V_i 独立执行缩放点积注意力。
    2. 将多个头的输出拼接在一起。
    3. 通过一个额外的线性变换，得到最终输出。
  • 作用：让模型能同时关注来自不同位置的不同表示子空间的信息。

Decoder-only Transformer

以GPT系列为代表的Decoder-only架构是当前大语言模型的主流。

工作流程

对于输入序列 $w_1, \dots, w_t$，模型的工作流程是一个不断循环的过程：

  1. 编码与计算： 通过 Transformer 块（包含掩码多头自注意力、前馈网络等）计算每个位置的隐藏表示。此时得到的矩阵包含了所有历史信息。

  2. 预测下一个： 取出最后一个位置（$w_t$）的隐藏表示 $h_t$。 通过输出投影层（线性层）将其映射到词汇表维度，再经过 Softmax 得到概率分布 $P(w_{t+1} | w_1, \dots, w_t)$。 选择概率最高的词（或采样）作为预测结果 $w_{t+1}$。

  3. 循环迭代： 将新生成的 $w_{t+1}$ 加入序列末尾，形成新的输入序列 $w_1, \dots, w_t, w_{t+1}$，重复步骤 1 和 2。

直观理解：这就是一个“接龙”游戏。模型每走一步，都要回头看看自己走了多远（因果掩码），然后决定下一步踩在哪里。

关键组件

位置编码 (Positional Encoding)： - 问题：自注意力本身是置换等变的，即打乱输入顺序，输出也会相应打乱，但它无法感知词语的顺序。“V我50”和“我V50”对它来说一样。 - 解决方案：在输入Embedding中加入位置信息，可以是固定的三角函数编码，也可以是可学习的向量。

因果掩码 (Causal Masking)： - 问题：在预测第 t 个词时，模型不能“偷看”到第 t+1 个及之后的词，否则就是作弊。 - 解决方案：在计算注意力分数时，将对未来位置的分数设置为负无穷大，这样经过Softmax后，它们的权重就会变为0。

$$A_{ij} = \begin{cases} Q_i K_j^T / \sqrt{d_k}, & j \le i \\ -\infty, & j > i \end{cases}$$

Transformer Block结构： 一个标准的Transformer Block由以下几个部分组成，它们通过残差连接和层归一化组合在一起： - 掩码多头自注意力 (Masked Multi-Head Self-Attention) - 前馈网络 (Feed-Forward Network, FFN)：对每个位置的表示进行独立的非线性变换，增加模型的容量。 - 残差连接 (Residual Connection)：X' = X + Attention(X)，帮助梯度流动，训练更深网络。 - 层归一化 (Layer Normalization)：稳定训练过程。

完整Block公式：

$$X' = \text{LayerNorm}(X + \text{Attention}(X))$$

$$X'' = \text{LayerNorm}(X' + \text{FFN}(X'))$$

总结

下面总结Transformer成功的原因：

  • 架构优势：
    • 全局交互：任意两个位置的词都可以直接交互，解决了长距离依赖问题。
    • 高度并行：整个序列可以同时进行计算，非常适合GPU加速。
    • 易于扩展：结构模块化，可以通过堆叠更多层、增加隐层维度等方式轻松扩大模型规模。
  • 实践优势：在大规模数据上表现卓越，已被无数研究和应用所验证，成为现代深度学习（尤其是NLP和多模态领域）的基石。
